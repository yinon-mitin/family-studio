Оболочка Family Studio: план реализации

Для исполнителей: обязательный подскилл — superpowers:subagent-driven-development (рекомендуется) или superpowers:executing-plans. Шаги отмечаются галочками. Работать в отдельной ветке feat/shell.

Цель. Обернуть существующий конструктор герба в общую оболочку с реестром инструментов, адресной маршрутизацией и стиранием данных всех инструментов, чтобы на неё потом встали «Моя семья» и «Генограмма».

Архитектура. Новая папка src/shell: чистая функция выбора инструмента по адресу, реестр, маленькое хранилище текущего инструмента, компоненты Shell и ToolBar. Герб подключается как один из инструментов без изменения его внутренней логики; из его шапки и стартового экрана убирается переключатель языка (он переезжает в оболочку).

Стек. Vite, TypeScript (strict), Preact, Vitest, Playwright. Новых зависимостей нет.

Спецификация. docs/superpowers/specs/2026-11-10-family-studio-design.html

Общие ограничения

  • Node ≥ 20.19. Новых зависимостей не добавлять.
  • Ключи localStorage (family-crest:autosave:v1, family-crest:lang), метка файла family-crest и префикс имён файлов не меняются.
  • Словари src/i18n/ru.ts и src/i18n/en.ts содержат одинаковые ключи (проверяет tests/i18n.test.ts), английский текст без кириллицы.
  • Название оболочки: Студия семьи / Family Studio. Название вкладки герба: Герб семьи / Family crest.
  • Базовый путь сайта /family-studio/. Внешних запросов нет.
  • Каждая задача идёт по RED-GREEN и заканчивается коммитом, в который входит строка в CHANGELOG.md (раздел Unreleased).

Фокус проверки

  • Неизвестное или повторяющееся значение ?tool= и ?only= не должно ломать страницу: показывается первый доступный инструмент (Задача 1).
  • ?only= побеждает ?tool=, и при нём вкладок нет (Задача 1).
  • Если clearData() одного инструмента бросает исключение (хранилище заблокировано), остальные всё равно стираются (Задача 2).
  • Заголовок вкладки браузера меняется вместе с языком и инструментом (Задача 3).
  • Переключатель языка на странице один, а не два (Задача 3).
  • Отказ в подтверждении «Стереть всё» ничего не стирает (Задача 4).

Задача 1: выбор инструмента по адресу

Создать: src/shell/types.ts, src/shell/route.ts. Тест: tests/shell-route.test.ts.

Производит:

// types.ts
export type ToolId = 'genogram' | 'my-family' | 'crest';
export const TOOL_IDS: readonly ToolId[] = ['genogram', 'my-family', 'crest'];
export interface ToolDef {
  id: ToolId;
  title(): string;                 // название вкладки на текущем языке
  Component: import('preact').FunctionComponent;
  clearData(): void;               // стирает всё, что инструмент хранит на устройстве
}
// route.ts
export interface Route { tool: ToolId; showTabs: boolean }
export function resolveRoute(search: string, available: ToolId[]): Route;
export function toolUrl(search: string, tool: ToolId): string; // возвращает строку вида '?lang=en&tool=crest'
  • Шаг 1. Тест (RED). В tests/shell-route.test.ts, ожидаемые значения: 
    resolveRoute('', ['my-family','crest'])                      → { tool:'my-family', showTabs:true }
resolveRoute('?tool=crest', ['my-family','crest'])           → { tool:'crest', showTabs:true }
resolveRoute('?tool=nope', ['my-family','crest'])            → { tool:'my-family', showTabs:true }
resolveRoute('?tool=genogram', ['my-family','crest'])        → { tool:'my-family', showTabs:true }  // не зарегистрирован
resolveRoute('?only=crest', ['my-family','crest'])           → { tool:'crest', showTabs:false }
resolveRoute('?only=crest&tool=my-family', ['my-family','crest']) → { tool:'crest', showTabs:false }
resolveRoute('?only=nope', ['my-family','crest'])            → { tool:'my-family', showTabs:true }
resolveRoute('', ['crest'])                                  → { tool:'crest', showTabs:false }     // один инструмент
resolveRoute('?tool=crest&tool=my-family', ['my-family','crest']) → { tool:'crest', showTabs:true } // берётся первое значение
toolUrl('?lang=en', 'crest')            === '?lang=en&tool=crest'
toolUrl('?lang=en&only=crest', 'my-family') === '?lang=en&tool=my-family'  // only удаляется
toolUrl('', 'crest')                    === '?tool=crest'
  • Шаг 2. Запустить npx vitest run tests/shell-route.test.ts. Ожидается FAIL: модуль не найден.
  • Шаг 3. Реализовать resolveRoute и toolUrl на URLSearchParams. available не пустой; пустой список — ошибка программиста (бросить Error).
  • Шаг 4. Запустить тест. Ожидается PASS.
  • Шаг 5. Коммит: feat(shell): route resolution.
